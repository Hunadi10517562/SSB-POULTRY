# SSB Poultry Website

A responsive, multi-page web application designed for **SSB Poultry**, a local agricultural enterprise specializing in broiler chickens, farm-fresh eggs, and nutritional poultry feed.

---

##  Project Pages & Structure

- **`index.html`** - Homepage featuring hero showcase and core business highlights.
- **`about.html`** - About Us page detailing business mission, values, and story.
- **`products.html`** - Product catalog featuring broiler chicks, full-grown live chickens, fresh egg trays, and 50kg feed bags.
- **`enquiry.html`** - Interactive sales form with dynamic cost estimation and client-side input validation.
- **`contact.html`** - Contact page with direct messaging form, contact information, and farm location details.
- **`css/style.css`** - Global stylesheet maintaining clean layout, typography, and responsive grid system.
- **`robots.txt`** - Off-page SEO directive file instructing web crawlers on page indexing rules.
- **`sitemap.xml`** - XML site structure mapping all pages for search engines like Google.

---

##  Features & Functionality

1. **Client-Side Form Validation:** Enforces character lengths, valid email structures, and required fields before submission.
2. **Dynamic Price Calculator:** Automatically computes line-item subtotal values in real-time as users adjust quantity or product selections on the enquiry page.
3. **On-Page & Off-Page SEO:** Configured with specific title tags, open graph meta properties, image `alt` attributes, canonical tags, `robots.txt`, and `sitemap.xml`.
4. **Responsive Layout:** Designed with fluid grids and media queries to adapt to desktop screens, tablets, and mobile devices.

---

## How to Run Locally

1. Open Visual Studio Code (VS Code).
2. Go to **File > Open Folder...** and select the `SSB_Poultry` directory.
3. Install the **Live Server** extension in VS Code.
4. Right-click `index.html` and select **Open with Live Server**.
5. Navigate through the site using the header navigation menu.
